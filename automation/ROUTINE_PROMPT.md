# スケジュール済みタスク用の指示（コピペ用）

リポジトリを GitHub に push したあと、Claude のスケジュール機能で
「2週間ごと」などの周期を設定し、下記をそのまま指示文として貼る。

---

このリポジトリは「見逃さん」というサブスク・キャンペーン通知アプリです。
`automation/CURATION.md` の手順に従って、キャンペーン情報の定期更新を1サイクル実行してください。

具体的に：

1. `automation/sources.json` の各 URL を開いて、いまのオファー内容・無料期間の日数・受付締切日（無ければ null）・対象者を確認する。公式サイトの文章は転載せず、自分の言葉で要約する。
2. `campaigns.js` の該当エントリと突き合わせ、
   - 変わっていたら内容を更新し `lastChecked` を今日の日付、`source: "公式"` にする
   - ページが表示できない／記載が曖昧なものは変更しない
   - オファーが消えている／404 のものは削除を提案する（コメントで理由を残す）
3. 巡回リストに無い新しい無料トライアル・期間限定特典を軽く検索で探し、見つけたら `automation/CANDIDATES.md` に「サービス名・要約・締切・公式URL・確認状況」を追記する（`campaigns.js` には入れない）。
4. `campaign-refresh/<今日の日付>` というブランチを作って変更をコミットし、Pull Request を出す。PR 本文に「✅更新 / ⚠️確認できず / 🆕新規候補 / 🗑️削除提案」を箇条書きでまとめる。
5. 迷ったら「載せない・変えない」。推測で日付を入れない。

作業内容は必ず PR にとどめ、`main` へは直接コミットしないこと。
